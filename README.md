# 🧩 신나는 도형 & 칠교놀이 (Tangram Fun)

> **특수교육(지적장애학생) 및 전자칠판 수업에 최적화된 인터랙티브 칠교놀이 웹 애플리케이션**

---

## 🌟 주요 특징

1. **지적장애학생 맞춤형 힌트 & 가이드선**
   - 칠교 내부 분할 점선 및 **색상 일치 가이드선 (28% 반투명 틴트)** 제공
   - 막히는 조각을 즉시 찾아주는 **✨ 조각 1개 자동 힌트** 기능
2. **칠교놀이의 왕 스타일 조작감**
   - **원터치 탭 45° 즉시 회전**: 조각을 가볍게 톡 터치하는 것만으로 45도 회전
   - **30px 자석 스냅(Snap)**: 목표 지점 근처에 도달하면 만족스러운 "딸깍" 소리와 함께 자동 흡착
3. **풍부한 테마별 스테이지 & 별점 시스템**
   - 📐 **기하도형**: 정사각형, 거대한 삼각형, 사다리꼴
   - 🐱 **동물친구**: 헤엄치는 물고기, 호수의 백조, 영리한 여우
   - ⛵ **사물·탈것**: 아늑한 집, 바다의 돛단배
   - 클리어 시간에 따른 **별 3개(⭐⭐⭐)** 평가 팡파르
4. **전자칠판 최적화 2인 대결 모드 (좌우 분할)**
   - 두 학생이 칠판 좌우에 서서 동시에 플레이할 수 있는 **좌우 분할(split-vertical)** 레이아웃
   - **멀티터치 완벽 지원**: 화면을 동시에 터치하여 각자의 조각을 독립 조작 가능
5. **웹 접근성 & 고대비 모드**
   - 최소 70px 이상의 터치 타깃 규격 준수
   - 3.5px 이상의 선명한 외곽선(Stroke) 및 고대비(◐) 모드 지원

## 📁 프로젝트 구조

```text
├── index.html                           # 메인 실행 웹페이지
├── README.md                            # 프로젝트 안내 문서
├── css/
│   ├── main.css                         # 전체 레이아웃 및 공통 스타일
│   ├── accessibility.css                # 웹 접근성 및 고대비 모드
│   └── game-board.css                   # 칠교 보드, 힌트 가이드선, 스냅 애니메이션
├── assets/
│   ├── shapes/                          # 고해상도 SVG 도형 에셋
│   ├── silhouettes/                     # 퍼즐 틀 실루엣 에셋
│   └── ui/                              # 조작 아이콘
└── js/
    ├── audio.js                         # Web Audio API 사운드 합성 매니저
    ├── tangram-data.js                  # 칠교 기하 좌표 및 테마별 스테이지 데이터
    ├── drag-engine.js                   # 멀티터치 & 탭 회전 자석 스냅 엔진
    ├── mode1-basic.js                   # 1단계: 기본 도형 맞추기
    ├── mode2-tangram.js                 # 2단계: 1인 칠교놀이 (힌트/타이머/별점)
    ├── mode3-two-player.js              # 3단계: 2인 전자칠판 좌우 대결
    └── app.js                           # 앱 컨트롤러 및 축하 폭죽 파티클
```
